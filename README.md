# APP-EMMA

App web para organizar y copiar rápidamente los mensajes de Guest Service.

## Cómo usar

1. Abre el archivo `index.html` en tu navegador (Chrome recomendado).
   - También puedes activar **GitHub Pages** en la configuración del repo para abrirla online:
     `https://memmamx.github.io/APP-EMMA/`
2. Selecciona **título** (Hombre / Mujer / Neutral) y escribe el **apellido** del huésped.
3. Toca cualquier mensaje para **copiarlo** al portapapeles.
4. Toca un idioma (**Inglés, Español, Francés, Alemán, Portugués**) para **traducir** el último mensaje copiado.
5. El traductor usa **MyMemory** (servicio gratuito).

> Por ahora solo se incluye la primera sección del archivo `APP-EMMA.txt`: **BIENVENIDA / DESPEDIDA**.
